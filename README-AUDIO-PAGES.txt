This package contains:

- reviews/ (the 23 written-review pages from the previous package)

The homepage now links:
- "Read review" to reviews/<film>.html for the 23 written-review titles.
- "Listen to audio review" to audio-reviews/<film>.html for the other 42 titles.

ADDING AN AUDIO FILE:
1. Upload the MP3 file into your website's existing audio/ folder in GitHub.
2. Open the matching page in audio-reviews/.
3. Find the clearly labelled black audio placeholder.
4. In the <source src="..."> line, replace the REPLACE-WITH-...mp3 filename with your actual MP3 filename.
5. Commit the changed page and uploaded MP3 to GitHub.

The Iron Claw page is already set to use the existing audio/iron-claw-review.mp3 file.
The MP3 itself is not included in this ZIP; keep your existing audio folder in GitHub.

IMPORTANT:
- Upload index.html, reviews/, and audio-reviews/ into the root of your existing GitHub Pages repository.
- Keep your existing images/, audio/, CSS, and other site assets.
- Do not upload this ZIP as a ZIP file; extract it first.
